# Prototype Templates

Use this directory for hardware and software prototype variants.

Suggested variants:

- `reference-phone/` — vendor-neutral reference design.
- `dev-phone/` — development hardware with debugging enabled.
- `production-like/` — production security defaults.
- `memory-lab/` — RAM and memory-controller simulation.
- `display-lab/` — display/touch experiments.
- `camera-lab/` — camera/ISP experiments.

Each prototype should contain configuration, BOM, interface definitions, validation results and build metadata.
