# PhoneOS Core

Original vendor-neutral mobile operating-system framework.

Layers:

- kernel boundary
- process and thread manager
- IPC/message bus
- virtual memory manager
- permissions and sandbox policy
- power/resource manager
- service registry
- application lifecycle
- diagnostics and logging

This framework is designed to sit above a supported ARM64 kernel/BSP. It is not Apple's iOS source and is not a replacement for AOSP.
