ArkansasIo · Phone Platform Research

UniversalPhoneOS

A modular phone prototype and operating-system research platform spanning Android, Kotlin Multiplatform, C++ reference components, hardware abstraction, drivers, firmware, applications, and backend services.

GitHub Repository Build & CI Documentation

OS Core

Shared runtime and platform abstractions intended to keep core phone behavior portable across implementations.

Android

Android application layer for exercising the UniversalPhoneOS runtime on conventional devices.

Hardware

HAL, driver, firmware, and prototype directories provide the foundation for future custom-phone hardware work.

Reference Model

C++20 components provide a deterministic reference implementation for low-level behavior and testing.

Applications

Prototype application surfaces can be developed independently while sharing platform services.

CI

GitHub Actions validates the C++ model, Kotlin tests, and Android debug build on every main-branch change.

Development status: research prototype. A successful software build does not imply production phone hardware, modem certification, or device certification.
