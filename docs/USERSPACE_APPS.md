# System Application Contracts

Candidate original apps:

- Launcher: app grid, home screen, widgets and task switching
- Settings: connectivity, display, power, accounts, accessibility and privacy
- Phone: telephony UI; depends on supported modem/RIL services
- Messages: SMS/MMS/RCS where supported by the platform and carrier
- Contacts: contact storage, search and permissions
- Camera: preview, capture, lens selection and media library integration
- Gallery: photo/video browsing and metadata
- Browser: standards-compliant web engine integration
- Calculator and clock: local utility apps
- File manager: scoped storage access and explicit user permissions

The root repository does not yet contain production app implementations.
