# Thermal Test Plan

1. Record ambient temperature and prototype revision.
2. Instrument SoC, battery, DRAM, display and RF zones where available.
3. Run CPU/GPU/NPU workloads independently and concurrently.
4. Run sustained camera/video recording and cellular throughput.
5. Test charging while under workload only within validated battery/charger limits.
6. Measure surface temperature, throttling, battery current and frame/network stability.
7. Verify thermal warning, throttling and emergency shutdown paths.
8. Repeat over supported ambient and battery states using vendor limits.

This plan does not specify unsafe test voltages or battery charging parameters.
