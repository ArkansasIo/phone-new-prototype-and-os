# iOS-Class Platform Notes

This folder documents an independent mobile OS architecture with similar broad capabilities: app lifecycle, graphics, media, networking, sensors, privacy controls, secure storage, sandboxing, updates and accessibility. It is not Apple iOS and does not include Apple source code, proprietary frameworks, device firmware, signing keys or private APIs.

For a real prototype, use hardware and boot firmware the team is authorized to program, then implement original system services and application APIs on a supported kernel.
